# Hồ sơ học tập Nguyễn Bá Long

Trang công khai: https://longnguyen5123.github.io/longnguyenpvu/

## Cập nhật bài tập và dự án
Mở https://long-geology-portfolio.kagi5197.chatgpt.site/admin và đăng nhập bằng tài khoản chủ website hiện tại. Thêm/sửa bài tập hoặc dự án, rồi bấm **Lưu lên website**. Tải lại trang công khai để xem nội dung mới. Không có nút quản trị trên trang công khai.

Giao diện công khai chạy trên GitHub Pages; đăng nhập, quyền chỉnh sửa và dữ liệu vẫn do Sites cung cấp. Đăng nhập GitHub không thay thế đăng nhập quản trị Sites. Không sao chép mật khẩu hay khóa bí mật vào kho mã này.

## Sửa thông tin giới thiệu và liên hệ
Đăng nhập GitHub bằng tài khoản sở hữu kho mã, mở index.html, chọn biểu tượng bút chì và lưu bằng **Commit changes**. Sửa màu sắc/bố cục trong portfolio.css. Bài tập/dự án lấy dữ liệu trực tiếp từ Sites, không sửa trong HTML.

## Bật GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Dữ liệu
content.js chỉ đọc nội dung công khai. Các mục ẩn không được API trả về. Nếu dịch vụ dữ liệu tạm thời không hoạt động, trang hiển thị thông báo thử lại thay vì dữ liệu cũ. Giữ website Sites hoạt động để tiếp tục đăng nhập và cập nhật.
